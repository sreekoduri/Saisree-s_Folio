## 📂 Project Setup

Clone the repository:

```bash
git clone https://github.com/sreekoduri/Saisree-s_Folio.git
```

Go to project folder:

```bash
cd Saisree-s_Folio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm start
```

---

## 📦 Build for Production

```bash
npm run build
```
